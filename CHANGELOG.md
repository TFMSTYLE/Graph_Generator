# Changelog

## 1.2.3

The source code is now in this repository, with the license it has always been released under.

- Added the GPL 3.0 license text and a copyright notice
- The package now lists exactly which files it holds
- Restored the store name and tags

## 1.2.2

Released on the Blender store on 2025-11-15.

blender versioning reverted back from 4.2.0 to 4.4.0

## 1.2.1

Released on the Blender store on 2025-11-15.

Fix report issue site and tag

## 1.2.0

Released on the Blender store on 2025-11-15.

System overhaul:
- New keyframe save system (no more hash issues)
- New support for Armature and bones (with bone filter on multi bone graphs)
- New Peak source preset
- Cleaner UI
- New global graph reset (to clear all saved graph from memory)

## 1.0.6

Released on the Blender store on 2025-10-22.

- Added Tags

## 1.0.5

Released on the Blender store on 2025-10-18.

- Replaced depreciated functions for blender 5+ compatibility check.
- Minimum Blender version changed from 4.2 to 4.4

## 1.0.1

Released on the Blender store on 2025-10-17.

- Added Multiple Keyframe interpolations. The Graph Generator will now follow the curve of the original graph that has more than 2 saved keyframes.

## 1.0.0

Released on the Blender store on 2025-10-17.

Initial Release.
